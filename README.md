# 🏏 IPL Analysis Dashboard: Historical IPL Insights (2008–2024)

A dynamic and interactive Power BI dashboard developed to analyze Indian Premier League (IPL) data from 2008 to 2024. The dashboard provides comprehensive insights into team performance, player achievements, batting and bowling statistics, tournament outcomes, and match-winning trends through engaging visualizations.

---

# 📌 Short Description / Purpose

The IPL Analysis Dashboard is a comprehensive sports analytics solution built in Power BI to help users explore and analyze historical IPL data spanning 17 seasons (2008–2024).

The dashboard enables cricket enthusiasts, sports analysts, coaches, franchise management teams, and data professionals to uncover patterns, evaluate player performances, compare team success, and gain valuable insights into IPL history through interactive visualizations.

---

# 🛠️ Tech Stack

The dashboard was built using the following tools and technologies:

### 📊 Power BI Desktop

Primary platform used to create interactive reports and visualizations.

### 📂 Power Query

Used for data cleaning, transformation, and preprocessing.

### 🧠 DAX (Data Analysis Expressions)

Implemented for calculated measures, KPIs, player statistics, and dynamic calculations.

### 🔗 Data Modeling

Established relationships between matches, teams, and player datasets for effective analysis and filtering.

### 📈 Data Visualization

Utilized KPI cards, bar charts, donut charts, slicers, and interactive visuals to present insights effectively.

### 📁 File Formats

* `.pbix` for dashboard development
* `.csv` for dataset storage
* `.png` for dashboard preview images

# 📂 Data Source

### Source

IPL Historical Dataset (2008–2024)

The dataset contains detailed information on IPL matches conducted between 2008 and 2024, including:

* Match Results
* Team Information
* Player Details
* Batting Statistics
* Bowling Statistics
* Toss Decisions
* Match Winners
* Player of the Match Awards
* Tournament Winners
* Runs, Fours, Sixes, and Wickets Data

The raw dataset was cleaned and transformed using Power Query before being modeled and visualized in Power BI.

# ✨ Features / Highlights

## Business Problem

The Indian Premier League has generated a vast amount of cricket data over multiple seasons. While this data contains valuable insights, extracting meaningful information regarding player performance, team consistency, and match-winning strategies can be challenging.

Some key questions include:

* Which teams have been the most successful in IPL history?
* Who are the highest run scorers and wicket takers?
* Which players consistently deliver match-winning performances?
* How does toss decision impact match results?
* Which franchises dominate across multiple seasons?

---

## Goal of the Dashboard

The primary objective of this dashboard is to:

* Analyze IPL data from 2008–2024.
* Compare team performances across seasons.
* Evaluate batting and bowling achievements.
* Identify long-term player trends.
* Understand factors influencing match outcomes.
* Provide interactive sports analytics through data visualization.
